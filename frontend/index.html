Guía de nomenclatura

1 = gana el local · X = empate · 2 = gana la visita.
1X = local o empate · X2 = empate o visita · 12 = gana uno de los dos, sin empate.
G = Ganado · E = Empatado · P = Perdido.
Ambos Marcan — Sí = los dos equipos anotan al menos un gol · No = uno o ambos no anotan.
+2,5 = 3 o más · −2,5 = 2 o menos · +3,5 = 4 o más · −3,5 = 3 o menos.
Cuotas 1X2 = cuotas del mercado para Local / Empate / Visita.
Bajas = lesionados o suspendidos encontrados para el partido.
VAR = árbitro asistente de video.
Confianza: 🟢 Alta · 🟡 Media · 🔴 Baja.
Sin color: se calcula el porcentaje, pero faltan datos arbitrales suficientes para calificar la confianza de tarjetas.
% = probabilidad estimada; no representa una garantía de resultado.
